MÓDULO 6 - Camada de Enlace de Dados

🔍 Protocolo ARP (Address Resolution Protocol)

O protocolo ARP mapeia endereços IP (lógicos) para endereços MAC (físicos).

  • Request: "Quem tem o IP X.X.X.X?" (Broadcast para FF:FF:FF:FF:FF:FF)
  • Reply: "Sou eu! Meu MAC é XX:XX:XX:XX:XX:XX" (Unicast)
  • Tabela ARP: Cache de mapeamentos IP→MAC

🔀 Métodos de Comutação de Switches

Store-and-Forward: Armazena quadro completo, verifica CRC - Mais confiável, porém mais lento

Cut-Through: Encaminha após ler MAC de destino (6 bytes) - Menor latência, não verifica erros

Fragment-Free: Analisa primeiros 64 bytes - Equilibra velocidade e confiabilidade

🏷️ Endereços MAC

  • 48 bits (6 bytes) em hexadecimal - Formato: XX:XX:XX:XX:XX:XX
  • Primeiros 3 bytes: OUI (fabricante IEEE atribui)
  • Últimos 3 bytes: número único do dispositivo
  • Broadcast: FF:FF:FF:FF:FF:FF (todos recebem)

↔️ Half-Duplex vs Full-Duplex

Half-Duplex: Uma direção por vez (rádio)

Full-Duplex: Duas direções simultâneas (telefone)

🌳 Topologias de Rede

  • Estrela: Todos conectados a ponto central (switch) - Mais comum, fácil instalação/manutenção
  • Barramento: Todos em um cabo compartilhado - Legacy, colisões frequentes
  • Anel: Dispositivos em círculo (Token Ring) - Legacy, token passa sequencialmente
  • Malha: Todos interconectados - Alta disponibilidade, redundância máxima
  • Ponto a Ponto: Conexão direta entre dois dispositivos - WAN simples

📊 Tabela MAC (CAM Table)

O switch aprende e mantém tabela de endereços:

  • Aprendizado: Registra MAC de origem e porta ao receber frame
  • Encaminhamento: Consulta tabela para enviar apenas pela porta correta
  • Flooding: Se MAC desconhecido, envia por todas as portas (exceto origem)
  • Aging: Entradas expiram após ~5 minutos de inatividade

🔄 Processo ARP Detalhado

Cenário: Host A (192.168.1.10) quer comunicar com Host B (192.168.1.20)

  1. Host A verifica se conhece MAC de 192.168.1.20 na tabela ARP local
  2. Se não conhece, envia ARP Request (broadcast): "Quem tem 192.168.1.20?"
  3. Todos na LAN recebem, mas só Host B responde
  4. Host B envia ARP Reply (unicast): "Sou eu! MAC: AA:BB:CC:DD:EE:FF"
  5. Host A armazena na tabela ARP e envia dados usando o MAC descoberto

💻 Comandos Úteis

  • ipconfig /all (Windows) - Ver configurações de rede e MAC
  • arp -a - Ver tabela ARP local
  • ifconfig (Linux/Mac) - Configurações de interface
  • ip link show (Linux) - Ver endereços MAC

Flashcards - Clique para Virar

O que é o protocolo ARP?
Address Resolution Protocol - mapeia endereços IP (lógicos) para endereços MAC (físicos). Usado em conjunto com protocolos de rede para comunicação em LAN.
Qual o formato de um endereço MAC?
48 bits (6 bytes) em hexadecimal: XX:XX:XX:XX:XX:XX. Primeiros 3 bytes: OUI (fabricante). Últimos 3 bytes: identificador único.
O que significa Store-and-Forward?
Método de switch que armazena o quadro inteiro, verifica erros (CRC) antes de encaminhar. Mais confiável, mas introduz maior latência.
Diferença entre Half-Duplex e Full-Duplex?
Half-Duplex: comunicação em uma direção por vez (ex: rádio). Full-Duplex: comunicação simultânea em ambas direções (ex: telefone).
O que é CSMA/CD?
Carrier Sense Multiple Access with Collision Detection - detecta e resolve colisões em redes Ethernet. Usado com hubs (obsoleto).
O que faz a subcamada LLC?
Logical Link Control - interface entre camadas superiores e MAC, identifica protocolos (IPv4/IPv6), gerencia multiplexação.
O que faz a subcamada MAC?
Media Access Control - gerencia acesso ao meio físico, controla endereçamento MAC, responsável por entrega hop-to-hop.
O que é CSMA/CA?
Carrier Sense Multiple Access with Collision Avoidance - evita colisões antes que ocorram, usado em redes Wi-Fi (IEEE 802.11).
Por que precisa de IP e MAC?
MAC: entrega hop-to-hop (nó a nó). IP: entrega end-to-end (origem ao destino final). Ambos são necessários paraFuncionamento da Internet.
Endereço MAC Broadcast?
FF:FF:FF:FF:FF:FF - enviado para todos os dispositivos na rede local (LAN). Usado em ARP requests e descoberta de rede.
Quantos bits tem um endereço IPv4?
32 bits divididos em 4 octetos, resultando em aproximadamente 4,3 bilhões (2³²) de endereços possíveis.
Quantos bits tem um endereço IPv6?
128 bits oferecendo 340 undecilhões (3,4 × 10³⁸) de endereços. Substitui IPv4 por esgotamento de endereços.
O que é TTL?
Time to Live - campo no cabeçalho IP que limita o tempo de vida do pacote. Cada roteador decrementa 1; se chegar a 0, descarta o pacote.
O que é um Gateway Padrão?
Roteador que conecta a rede local a outras redes externas. Configurado manualmente ou via DHCP, é a 'porta de saída' da LAN.
Diferença entre roteamento estático e dinâmico?
Estático: rotas configuradas manualmente, não se adapta. Dinâmico: roteadores aprendem automaticamente (OSPF, RIP, EIGRP, BGP).
O que é uma Rota Padrão?
Gateway of last resort (0.0.0.0/0 ou ::/0) - usada quando destino não está explicitamente na tabela de roteamento.
Características do IP?
Sem conexão (connectionless), melhor esforço (best effort), independente da mídia. Não garante entrega - TCP faz isso na camada 4.
O que é fragmentação IP?
Divisão de pacotes grandes em fragmentos menores para se adequar ao MTU da rede. Reassembly ocorre no destino.
Endereço Loopback IPv4?
127.0.0.1 (ou qualquer 127.0.0.0/8) - testa a pilha TCP/IP local. Pacotes nunca saem da interface.
O que é ICMP?
Internet Control Message Protocol - envia mensagens de erro e controle (ping, traceroute). Protocolo 1 no cabeçalho IP.
O que é a máscara de sub-rede?
Sequência de bits (1s para rede, 0s para host) que divide o endereço IP. Pode ser decimal (255.255.255.0) ou CIDR (/24).
O que é DHCP?
Dynamic Host Configuration Protocol - atribui automaticamente IP, máscara, gateway, DNS aos clientes. Usa portas UDP 67/68.
Endereço de Broadcast IPv4?
Todos bits de host = 1. Exemplo: 192.168.10.255/24. Enviado para todos dispositivos na rede local.
O que é VLSM?
Variable Length Subnet Mask - permite sub-redes de tamanhos diferentes, otimizando uso de endereços IP.
O que é NAT?
Network Address Translation - traduz IPs privados para público. Economiza endereços IPv4, mas dificulta conexão peer-to-peer.
Classes de IP: Classe A?
0.0.0.0 a 127.255.255.255 (/8). 1º bit = 0. 2²⁴ hosts por rede. Para redes muito grandes.
Classes de IP: Classe B?
128.0.0.0 a 191.255.255.255 (/16). Primeiros bits = 10. 2¹⁶ hosts. Redes médias a grandes.
Classes de IP: Classe C?
192.0.0.0 a 223.255.255.255 (/24). Primeiros bits = 110. 254 hosts. Redes pequenas.
Endereços Privados RFC 1918?
Classe A: 10.0.0.0/8, Classe B: 172.16.0.0/12, Classe C: 192.168.0.0/16. Não roteáveis na Internet.
O que é CIDR?
Classless Inter-Domain Routing - substituiu classes de IP em 1993. Usa notação de prefixo (ex: /24) para flexibilidade.
Topologia Estrela?
Todos dispositivos conectados a ponto central (switch/hub). Mais comum, falha em um cabo não afeta outros.
O que é um Switch Layer 2?
Dispositivo que opera na camada de enlace, usa tabela MAC (CAM table) para encaminhar frames apenas para porta correta.
O que é Cut-Through switching?
Encaminha frame após ler apenas MAC de destino (6 bytes). Menor latência, mas não detecta erros.
O que é Fragment-Free switching?
Analisa primeiros 64 bytes antes de encaminhar. Equilibra velocidade e confiabilidade, detecta colisões.
Protocolos de Roteamento Dinâmico?
RIP (vetor distância), OSPF (estado de enlace), EIGRP (híbrido Cisco), BGP (entre sistemas autônomos).

⚙️ Configuração DHCP Server

Arquivo /etc/dhcp/dhcpd.conf

option domain-name "labrc.ebu.br";
option domain-name-servers 8.8.8.8, 1.1.1.1;
default-lease-time 86400;
max-lease-time 604800;
authoritative;

subnet 192.168.1.0 netmask 255.255.255.0 {
    range 192.168.1.1 192.168.1.200;
    option subnet-mask 255.255.255.0;
    option broadcast-address 192.168.1.255;
    option routers 192.168.1.254;
}

# Reserva de IP por MAC
host workstation {
    hardware ethernet 08:00:27:83:4e:25;
    fixed-address 192.168.1.13;
}

host workstation2 {
    hardware ethernet 08:00:27:02:66:D0;
    deny booting;
}

📖 Explicação dos Parâmetros

  • option domain-name: Define o nome de domínio da rede
  • option domain-name-servers: Servidores DNS (Google 8.8.8.8, Cloudflare 1.1.1.1)
  • default-lease-time: Tempo padrão de concessão (86400s = 24h)
  • max-lease-time: Tempo máximo de concessão (604800s = 7 dias)
  • authoritative: Marca este servidor como autoritativo para a rede
  • range: Faixa de IPs dinâmicos disponíveis
  • hardware ethernet: Endereço MAC do dispositivo
  • fixed-address: IP fixo reservado para o MAC especificado
  • deny booting: Bloqueia o dispositivo de receber IP

� Processo DHCP (DORA)

O DHCP utiliza 4 mensagens para atribuir configuração IP automaticamente:

Portas: Cliente usa UDP 68, Servidor usa UDP 67 Broadcast: 255.255.255.255 (todos na rede)
  • DISCOVER: Cliente envia broadcast procurando servidores DHCP
  • OFFER: Servidor oferece configuração IP (endereço, máscara, gateway, DNS)
  • REQUEST: Cliente aceita a oferta e solicita confirmação (broadcast para informar outros servidores)
  • ACK: Servidor confirma com unicast, cliente pode usar o IP configurado
  • Lease Time: Tempo de validade da configuração (renovação automática antes de expirar)

🔐 Comandos de Hash e Checksum

MD5SUM (hash MD5 - 128 bits):
md5sum arquivo.txt                    # Gerar hash MD5
md5sum arquivo.txt > arquivo.md5      # Salvar hash em arquivo
md5sum -c arquivo.md5                 # Verificar integridade comparando hash
md5sum *.conf                         # Hash de múltiplos arquivos

SHA1SUM (hash SHA-1 - 160 bits):
sha1sum arquivo.txt                   # Gerar hash SHA-1
sha1sum arquivo.txt > arquivo.sha1    # Salvar hash

SHA256SUM (hash SHA-256 - 256 bits):
sha256sum arquivo.txt                 # Gerar hash SHA-256 (mais seguro)
sha256sum arquivo.txt > checksum.txt  # Salvar para verificação posterior
sha256sum -c checksum.txt             # Verificar integridade

SHA512SUM (hash SHA-512 - 512 bits):
sha512sum arquivo.txt                 # Hash mais seguro (512 bits)
sha512sum *.iso                       # Hash de arquivos grandes (ISOs)

Uso prático:
# Verificar integridade de download
wget http://site.com/arquivo.zip
wget http://site.com/arquivo.zip.sha256
sha256sum -c arquivo.zip.sha256       # Compara hash baixado

# Gerar hash de configurações importantes
md5sum /etc/dhcp/dhcpd.conf > /backup/dhcpd.md5
# Depois verificar se arquivo foi alterado
md5sum -c /backup/dhcpd.md5

# Hash de múltiplos arquivos para auditoria
sha256sum /etc/*.conf > /backup/config-hashes.txt

🔐 Permissões e Propriedade

Formato de permissões: rwxrwxrwx (user group others)
r = read (4), w = write (2), x = execute (1)

chmod 755 arquivo                     # rwxr-xr-x (dono: tudo, outros: ler+executar)
chmod 644 arquivo                     # rw-r--r-- (dono: ler+escrever, outros: só ler)
chmod 600 arquivo                     # rw------- (só dono pode ler e escrever)
chmod +x script.sh                    # Adicionar permissão de execução
chmod -w arquivo                      # Remover permissão de escrita

chownNota: User arquivo                    # Mudar dono
chownNota: User:group arquivo              # Mudar dono e grupo
chown -RNota: User:group /diretorio        # Recursivo em diretório

Exemplos comuns:
chmod 755 /usr/bin/script             # Scripts executáveis
chmod 644 /etc/arquivo.conf           # Arquivos de configuração
chmod 600 ~/.ssh/id_rsa               # Chave SSH privada

🗂️ Compressão e Arquivamento

TAR (arquivamento):
tar -czf backup.tar.gz /diretorio     # Criar arquivo comprimido (gzip)
tar -xzf arquivo.tar.gz               # Extrair arquivo .tar.gz
tar -cjf backup.tar.bz2 /dir          # Comprimir com bzip2
tar -xjf arquivo.tar.bz2              # Extrair .tar.bz2
tar -tzf arquivo.tar.gz               # Listar conteúdo sem extrair

ZIP:
zip -r backup.zip /diretorio          # Criar arquivo .zip
unzip arquivo.zip                     # Extrair .zip
unzip -l arquivo.zip                  # Listar conteúdo

GZIP:
gzip arquivo.txt                      # Comprimir (cria arquivo.txt.gz)
gunzip arquivo.txt.gz                 # Descomprimir
